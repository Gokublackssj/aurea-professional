# Créditos

Aurea es un hotel ficticio. Esta web es una demo conceptual de diseño y desarrollo.
Ninguna foto ni el vídeo muestran un hotel real llamado Aurea, ni se presentan como
tal: son referencias visuales para la demo.

La página `/creditos/` de la web repite esta lista con enlaces; las dos salen de
`src/data/fotos.ts`.
